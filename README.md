# MAX Chat · GREEN-API

Веб-интерфейс для отправки и получения текстовых сообщений в мессенджере **MAX** через [GREEN-API](https://green-api.com/max).
Внешний вид основан на [web.max.ru](https://web.max.ru/): список чатов слева, переписка справа.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev          # http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build
npm run preview
```

Перед входом нужно:

1. Создать инстанс MAX в [личном кабинете GREEN-API](https://console.green-api.com) и авторизовать его.
2. Для приёма входящих сообщений в настройках инстанса оставить **пустым** поле `webhookUrl` и включить уведомления о входящих сообщениях (при желании также об исходящих и о статусах). Без этого очередь `ReceiveNotification` останется пустой.
3. Если в кабинете указан персональный `apiUrl` (например, `https://1103.api.green-api.com`), ввести его в разделе «Дополнительно» на форме входа.
